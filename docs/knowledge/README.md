# 达人资料库说明

> **REFERENCE ONLY** — 本目录保存达人/作者的来源知识与整理笔记，不定义 Reading Map 产品架构或业务规则。领域语义以 `.codex/skills/reading-map-domain-model/SKILL.md` 为准。

这个目录保存给 AI、来源理解与导入校验使用的达人说明书，不直接作为前端路线文案展示。

每份说明书主要回答：

1. 这个达人/作者的定位是什么。
2. 他的路线靠哪些判断变量推进。
3. 原图、文字介绍、著作里哪些内容属于推荐事实、阶段说明、提醒或操作方法。
4. 哪些来源上下文必须保留，避免把不同年龄/阶段的同一素材错误合并。

`knowledge_type=source_manual` 适合达人方法论和路线说明，`knowledge_type=image_reading` 适合原图逐页读图摘要或人工校对后的 OCR 摘要。

来源书单抽取的当前工作流见 `.codex/skills/wild-reading-list-to-json/SKILL.md`。
