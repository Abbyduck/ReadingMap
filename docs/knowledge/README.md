# 达人资料库说明

这个目录保存给 AI 和导入校验使用的达人说明书，不直接作为前端路线文案展示。

每份说明书需要回答四个问题：

1. 这个达人/作者的定位是什么。
2. 他的路线靠哪些判断变量推进。
3. 原图、文字介绍、著作里哪些内容可以变成书单条目，哪些只能作为阶段说明、提醒或操作方法。
4. 后续用户自助导入 CSV 时，哪些字段必须被保留，避免把不同年龄/阶段的同一套书错误合并。

`knowledge_type=source_manual` 适合达人方法论和路线说明，`knowledge_type=image_reading` 适合原图逐页读图摘要或人工校对后的 OCR 摘要。

完整交接流程见 `docs/booklist-analysis-handoff.md`。
