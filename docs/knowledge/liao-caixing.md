# 廖彩杏 AI 资料库说明书

## 定位

廖彩杏是有声书学习法和 52 周计划型作者。她的路线不是严格分级读物体系，而是通过优质有声绘本、固定播放和循环复习建立英语语感。

## 核心方法

- 代表方法是有声书输入，强调耳朵先熟悉语言，再通过图画和文字建立关联。
- 常见原则是不要先背单词、不要先教音标、不要讲语法、不要翻译、不要测试。
- 选材偏重复句、韵律、图文对应强、音频质量高的经典绘本。
- 52 周计划的价值在“定时、定量、循环”：新书周和复习周共同组成路线，不是简单的 100 本书名列表。

## 本地资料

- `廖彩杏书单&52周计划表.xls`
- `廖彩杏介绍.txt`

后续导入时需要保留周次、复习循环、书名、音频使用方式和是否新书/复习书。不能只按书名导入，否则 52 周计划的价值会丢失。

## 入库规则

- 每周计划适合 `list_type=route`，用 `stage_title=Week N` 保存周次。
- 同一本书在新书周和复习周重复出现时，保留重复出现关系；复习关系进入 `role=review` 或 `raw_text`。
- 音频播放方式放入 `reading_mode=listening`、`raw_text` 或 `reminder`。
- 如果 `.xls` 暂时无法解析，先入库路线说明和早期周次样例，待安装/接入老 Excel 读取引擎后再全量抽取。

## 阶段理解

- 起步阶段：以音频熟悉、图画理解和亲子共听为主，家长不要求孩子输出。
- 新书输入阶段：按周加入新有声绘本，重点是韵律、重复句和图文对应。
- 循环复习阶段：把前几周材料重新播放和翻看，帮助孩子从熟悉声音过渡到理解内容。
- 长期执行阶段：继续按 52 周节奏推进，遇到难度过高的书可暂时跳过，优先保护兴趣。
